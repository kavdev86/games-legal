Политика конфиденциальности игры «Ярл: Оборона Севера»

Редакция от 27 октября 2026 года.

Какие данные собирает игра

Игра не требует регистрации. Разработчик не собирает имя, телефон, адрес электронной почты и другие контактные данные игроков. Игра не запрашивает доступ к контактам, фотографиям, камере, микрофону и местоположению.

Прогресс игры (постройки, волны, монеты, настройки звука, имя в рейтинге) хранится на устройстве игрока. В версии для ВКонтакте он также сохраняется в хранилище приложений ВКонтакте, привязанном к аккаунту игрока, чтобы игру можно было продолжить на другом устройстве. Имя из профиля ВКонтакте используется только как имя по умолчанию в рейтинге игры; рейтинг хранится на устройстве игрока, и имя другим игрокам не передаётся.

Чтобы делать игру лучше, мы собираем обезличенную статистику: прохождение обучения, достигнутые волны, длительность игры, показы рекламы, покупки, тип устройства и версию игры. Для этого используются AppMetrica (Android-версия) и Яндекс Метрика (веб-версия).

Реклама

В игре показывается реклама: в Android-версии — Рекламной сети Яндекса, в версии для ВКонтакте — рекламой ВКонтакте. Полноэкранная реклама появляется между волнами; часть наград игрок получает за добровольный просмотр рекламы. Для выбора объявлений рекламная сеть может использовать рекламный идентификатор устройства, сведения о модели устройства и приблизительном местоположении по IP-адресу. Рекламный идентификатор можно сбросить или ограничить в настройках Android. Рекламу между волнами можно отключить покупкой «Без рекламы».

Покупки

Оплату покупок в Android-версии проводит RuStore, в версии для ВКонтакте — ВКонтакте. Разработчик получает только сведения о покупке (какой товар куплен, номер заказа и, в версии для ВКонтакте, числовой идентификатор пользователя, нужный для подтверждения заказа) и не получает данные банковской карты.

Сторонние сервисы

  • AppMetrica, Яндекс Метрика, Рекламная сеть Яндекса — политика конфиденциальности Яндекса.
  • RuStore — политика конфиденциальности пользователей RuStore.
  • ВКонтакте — политика конфиденциальности ВКонтакте.

Дети

Игра не предназначена для сбора данных о детях и не запрашивает у игроков сведения о возрасте или личности.

Удаление данных

Игровые данные на устройстве удаляются вместе с игрой, при очистке данных приложения или кнопкой «Сбросить прогресс» в настройках игры. Данные в хранилище ВКонтакте удаляются по правилам ВКонтакте. Сведения о заказах на сервере разработчика удалим по письму на адрес ниже.
