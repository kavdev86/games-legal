Политика конфиденциальности игры «Башня Тихого Мастера»

Редакция от 26 октября 2026 года.

Какие данные собирает игра

Разработчик не собирает телефон, адрес электронной почты и другие контактные данные игроков. Игра не запрашивает доступ к контактам, фотографиям, камере, микрофону и местоположению.

Прогресс игры (уровень, запасы, рецепты, настройки) хранится на устройстве игрока и в облаке сервиса GamePush (в версиях для Яндекс Игр — в облаке Яндекс Игр). В Android-версии он также попадает в резервную копию Android, если она включена на устройстве. В версиях для ВКонтакте, Одноклассников, VK Play и Яндекс Игр прогресс привязан к аккаунту игрока на площадке.

Вход через VK ID в Android-версии — по желанию игрока. При входе игра получает от VK ID идентификатор пользователя, имя, фамилию и фотографию профиля. Имя с первой буквой фамилии и фотография показываются другим игрокам в таблицах игроков («Молва») и передаются для этого в GamePush. Чтобы тот же прогресс нашёлся на другом устройстве, игра хранит в хранилище приложений ВКонтакте (видно только этому аккаунту VK ID) служебный код игрока GamePush. Без входа игрок играет на устройстве анонимно и в таблицы игроков не попадает.

Чтобы делать игру лучше, мы собираем обезличенную статистику: какие окна открываются, сколько длится игровая сессия, какие покупки сделаны, сколько раз показана реклама, какие ошибки возникают, тип устройства и версия игры. Для этого используется сервис Яндекс Метрика.

Если игрок пишет разработчику через «Сообщить о проблеме» в настройках игры, текст сообщения и выбранная причина передаются через Яндекс Метрику. Игра просит не писать в сообщении имя, телефон и другие личные данные.

Реклама

В игре показывается реклама: в Android-версии — Рекламной сети Яндекса, в версиях для площадок — рекламой самой площадки. Часть наград игрок получает за добровольный просмотр рекламы. Для выбора объявлений рекламная сеть может использовать рекламный идентификатор устройства, сведения о модели устройства и приблизительном местоположении по IP-адресу. Рекламный идентификатор можно сбросить или ограничить в настройках Android.

Покупки

Оплату покупок в Android-версии проводит RuStore, в версиях для площадок — сама площадка. Разработчик получает только сведения о покупке (какой товар куплен и номер покупки) и не получает данные банковской карты.

Сторонние сервисы

  • Яндекс Метрика, Рекламная сеть Яндекса, Яндекс Игры — политика конфиденциальности Яндекса.
  • RuStore — политика конфиденциальности пользователей RuStore.
  • ВКонтакте, Одноклассники, VK Play, VK ID (вход в Android-версии) — политика конфиденциальности ВКонтакте.
  • Сохранения и таблицы игроков, в версиях для ВКонтакте, Одноклассников и VK Play также покупки — сервис GamePush.

Дети

Игра не предназначена для сбора данных о детях и не запрашивает у игроков сведения о возрасте или личности.

Удаление данных

Игровые данные на устройстве удаляются вместе с игрой или при очистке данных приложения. Прогресс в облаке площадки удаляется по правилам площадки. Прогресс в облаке GamePush и имя в таблицах игроков разработчик удалит по письму на адрес ниже. Доступ игры к VK ID можно отозвать в настройках аккаунта VK ID (раздел подключённых сервисов и приложений).
